# ERP System

This is a scalable and modular ERP system designed for automating educational centers. It focuses on managing students, teachers, class schedules, and financial reports.

## Technologies Used

- **Next.js** - React-based framework for building fast and scalable web applications.
- **Tailwind CSS** - Utility-first CSS framework for creating responsive designs.
- **shadcn/ui** - Pre-designed, reusable UI components.
- **TypeScript** - A strongly typed programming language for better code reliability.

## Features

- Manage student data (add, update, delete).
- Create and view teacher profiles.
- Schedule and automate class timetables.
- Generate financial reports and statistics.
- Responsive and modern user interface.

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/erp-system.git
   ```

cd erp-system

npm install

npm run dev

http://localhost:3000
